# Executive Intelligence

AI-powered executive leadership platform - Your Fractional CEO.

## Features

- **Business Health Scoring**: Multi-dimensional health assessment across all business areas
- **Strategic Planning**: OKR framework with goal tracking and progress monitoring
- **Board Reporting**: Executive-ready board decks and investor updates
- **C-Suite Coordination**: Unified view across CFO, CTO, COO, CHRO, CMO, CISO
- **Decision Support**: AI-powered decision analysis and recommendations
- **Growth Strategy**: Market expansion and scaling guidance
- **Enterprise Risk**: Comprehensive risk visibility across all dimensions
- **AI Consultation**: Claude-powered CEO consultant

## Tech Stack

- **Backend**: Flask, SQLAlchemy, PostgreSQL
- **AI**: Anthropic Claude API
- **Frontend**: Bootstrap 5
- **Deployment**: Render

## Quick Start

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=your-key
python web/app.py
```

## AI Conversation Modes

- **General**: General executive questions and guidance
- **Business Health**: Overall business health and performance
- **Strategic Planning**: Strategic planning and goal setting
- **Board Prep**: Board meeting preparation and reporting
- **Decision Support**: Executive decision support
- **C-Suite Review**: C-Suite performance review
- **Growth Strategy**: Growth strategy and planning
- **Risk Overview**: Enterprise risk overview
